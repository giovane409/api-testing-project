# API Testing Project

## About
A REST API project created as a learning and QA automation portfolio project.

## Current Features
- FastAPI application
- Task CRUD

## Tech Stack
- Python
- FastAPI
- Pydantic

## How to Run
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
fastapi dev main.py
